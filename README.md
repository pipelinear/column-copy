# Column Copy

**Select a column. Copy the whole page.**

A Chrome extension that reads your selected column from top to bottom, keeps the formatting, and lets you edit before copying. Full-page scanning, a visible scan line, and simple typo cleanup. Everything stays in your browser.

**[Download Column Copy](https://github.com/pipelinear/column-copy/raw/refs/heads/main/dist/column-copy.zip)**

1. Download and unzip.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped `column-copy` folder.

Click the extension, drag your column, then **Read page → Copy output**. **Option/Alt + Shift + R** reads again.

Works with accessible webpage text. No OCR; some embedded readers are restricted. [More details](docs/guide.md).
